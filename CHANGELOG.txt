Each folder holds the complete index.html for that version. The first line
inside every index.html names its version and date. Versions 1.1.0 and later
also include supabase-setup.sql (the same file in every version; already run
on the live database).


VERSION NUMBERS
---------------
Format MAJOR.MINOR.PATCH
  MAJOR  big redesigns or changes that break saved progress
  MINOR  new features (new courses, games, accounts)
  PATCH  bug fixes, wording and settings changes


HOW TO ROLL BACK
----------------
Upload index.html from an older folder to GitHub to replace the current one,
then commit. Do not roll back to 1.0.0 or 1.1.0 on the live site: those
versions have no account connection, so signed-in learners would lose sync
(their saved progress stays safe in Supabase).

v1.3.0  -  2026-11-20                                     Superseded
-----------------------------------------------------------------------------
Type: Minor (new features, inspired by CogniFit)
- 4 new brain games (11 total):
  - Tower Planner (planning): match the goal in the fewest moves
  - Quick Tap (hand-eye/speed): tap shrinking, later moving, targets
  - Switch It (task switching): card color sets the rule; shows switch cost
  - Night Watch (sustained attention): 2-4 minute watch for X; shows
    whether attention dips toward the end

  level down. Existing games start at their old difficulty. Square Recall's
  1-back/2-back chips are now Level 1-5 chips. Inner Clock has no levels.
- "My brain skills": Attention, Memory, Inhibition, Planning, Speed,
  0-100 from your last 5 rounds, with trend. Practice scores, not a test.
- "Today's workout": 3 games (~10 min) aimed at your two weakest skills,
  new each day, with a Next button between games. Counts workouts this
  week and all time; deliberately no streak.
- Fixed: "All games" on the end-of-game screen did nothing.
- Home button "Play a game" is now "Today's brain workout".
- New saved items lv, gl, wo, wd (synced). No database changes.
