VERSION NUMBERS
---------------
Format MAJOR.MINOR.PATCH
  MAJOR  big redesigns or changes that break saved progress
  MINOR  new features (new courses, games, accounts)
  PATCH  bug fixes, wording and settings changes


HOW TO ROLL BACK
----------------
Upload index.html from an older folder to GitHub to replace the current one,
then commit. Do not roll back to 1.0.0 or 1.1.0 on the live site: those
versions have no account connection, so signed-in learners would lose sync
(their saved progress stays safe in Supabase).

Type: Minor (feature improvement, from user feedback)
- Color Clash: optional 15-second warm-up with matching words to measure
  each player's own baseline speed (on by default, remembered).
- Times every correct answer; results show average time per answer,
  warm-up vs mixed-up speed, and slowdown % ("interference cost").
- Shows points from the last 5 rounds.
- End-of-round tip now fits the result: no misses -> go faster;
  few misses -> good balance; many misses -> slow down.
  (Old tip always said to slow down.)
- Start screen explains what "impulse" means in this game.
